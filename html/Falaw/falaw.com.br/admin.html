Publicação no GitHub

Com o token configurado, os artigos e membros da equipe criados no admin são salvos diretamente no repositório e ficam visíveis para todos imediatamente.

Crie um token em github.com → Settings → Developer settings → Personal access tokens → Fine-grained com permissão de escrita no repositório falaw.

Banco de Dados — Supabase

Conecte ao Supabase para sincronizar clientes, newsletter, contato e currículos em tempo real entre todos os dispositivos. Requer executar o script SQL em supabase-setup.sql no SQL Editor do Supabase.

Crie um projeto em supabase.com, vá em Settings → API e copie a Project URL e a anon public key. Com GitHub Token configurado, as páginas públicas são atualizadas automaticamente.

IA — Geração de Artigos

As chaves ficam salvas apenas neste navegador e nunca são enviadas ao repositório.

Cole a URL do webhook após importar e ativar o workflow no n8n. O arquivo do workflow está em n8n-workflow/falaw-ia-workflow.json.
